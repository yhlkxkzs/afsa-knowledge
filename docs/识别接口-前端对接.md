# 作物识别接口 — 前端对接说明

**接口地址**：`POST {baseUrl}/predict`（与知识库同端口，如 `http://host:32222/predict`）

---

## 一、请求：上传图片（二选一）

### 方式 1：表单上传（推荐，适合相机/相册选图）

- **Content-Type**：`multipart/form-data`
- **字段名**：`file` 或 `image`（任选其一）
- **值**：图片文件（二进制），支持常见格式：jpg、jpeg、png 等

前端示例（伪代码）：

```js
const formData = new FormData();
formData.append('file', imageFile);  // 或 formData.append('image', imageFile);

fetch(`${baseUrl}/predict`, {
  method: 'POST',
  body: formData,
  headers: {},  // 不要设 Content-Type，浏览器会自动带 boundary
});
```

### 方式 2：JSON + Base64

- **Content-Type**：`application/json`
- **Body**：`{ "image_base64": " base64 字符串 " }` 或 `{ "image": " base64 字符串 " }`

前端示例：

```js
// 将图片转为 base64 后发送
const base64 = await imageFileToBase64(imageFile);
fetch(`${baseUrl}/predict`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ image_base64: base64 }),
});
```

---

## 二、响应：统一结构（单模型 / 多模型都兼容）

成功时 **HTTP 200**，JSON  body 如下。前端可按「是否有 `model_results`」区分单模型 / 多模型。

### 1. 单模型（只开一个识别模型时）

```json
{
  "class": "apple",
  "confidence": 0.92,
  "low_confidence": false,
  "top_k": [
    { "class": "apple", "confidence": 0.92 },
    { "class": "tomato", "confidence": 0.05 },
    { "class": "pear", "confidence": 0.02 }
  ],
  "all_scores": { "apple": 0.92, "broccoli": 0.01, "grape": 0.01, "mango": 0.01, "peach": 0.01, "pear": 0.02, "strawberry": 0.01, "tomato": 0.05 },
  "sent_to_client": true,
  "sent_at": "2026-03-16T12:00:00.123456"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `class` | string | 识别结果类别（英文，如 apple、tomato） |
| `confidence` | number | 置信度 0～1 |
| `low_confidence` | boolean | 是否低于 0.6，可用来提示「不确定，建议重拍」 |
| `top_k` | array | 前 k 个候选，每项 `{ "class", "confidence" }` |
| `all_scores` | object | 所有类别的分数（可选展示） |
| `sent_to_client` | boolean | 固定 true |
| `sent_at` | string | ISO 时间 |

### 2. 多模型（开了多个识别模型时）

会多出 **`consistent`** 和 **`model_results`**，其余字段含义与单模型一致（`class` / `confidence` 为汇总结果）。

```json
{
  "consistent": true,
  "class": "apple",
  "confidence": 0.91,
  "low_confidence": false,
  "model_results": [
    { "model": "mobilenet_v3", "class": "apple", "confidence": 0.95, "low_confidence": false, "top_k": [...] },
    { "model": "efficientnet_lite0", "class": "apple", "confidence": 0.88, "low_confidence": false, "top_k": [...] },
    { "model": "shufflenet_v2", "class": "apple", "confidence": 0.91, "low_confidence": false, "top_k": [...] }
  ],
  "sent_to_client": true,
  "sent_at": "2026-03-16T12:00:00.123456"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `consistent` | boolean | 多个模型结果是否一致 |
| `class` | string | 一致时为统一结果；不一致时为多数票结果 |
| `confidence` | number | 一致时为各模型平均置信度；不一致时为最高置信度 |
| `model_results` | array | 每个模型的 `model`、`class`、`confidence`、`low_confidence`、`top_k`，用于展示「模型 A：苹果 0.95；模型 B：苹果 0.88」等 |

不一致示例（仅示意）：

```json
{
  "consistent": false,
  "class": "apple",
  "confidence": 0.95,
  "low_confidence": true,
  "model_results": [
    { "model": "mobilenet_v3", "class": "apple", "confidence": 0.95, "top_k": [...] },
    { "model": "efficientnet_lite0", "class": "apple", "confidence": 0.88, "top_k": [...] },
    { "model": "shufflenet_v2", "class": "pear", "confidence": 0.6, "top_k": [...] }
  ],
  "sent_to_client": true,
  "sent_at": "..."
}
```

---

## 三、错误响应

- **400**：未传图或图片无效  
  `{ "error": "no image: send form 'file' or JSON 'image_base64'" }` 或 `{ "error": "invalid image file: ..." }`
- **500**：服务未加载模型或推理异常  
  `{ "error": "model not loaded" }` 或 `{ "error": "..." }`

---

## 四、前端适配建议

1. **发请求**：优先用 **表单 `file`（或 `image`）** 上传原图，避免 base64 体积大。
2. **解析结果**：
   - 若有 `model_results`：按多模型 UI 展示（是否一致 + 各模型 `class`、`confidence`）。
   - 若无 `model_results`：按单模型展示，用 `class`、`confidence`、`top_k` 即可。
3. **统一字段**：单模型和多模型都有 **`class`**、**`confidence`**、**`low_confidence`**，可直接用作主结果；多模型时再根据 `consistent` 和 `model_results` 做补充展示。
4. **类别名**：当前为英文（如 apple、tomato），前端可自建中英文映射后展示。
