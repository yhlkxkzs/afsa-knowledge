# 知识库内容纲要与说明

本文档描述 App 知识库中**病害知识、虫害知识、防治方案、通用知识**的纲要与内容来源，便于后续增删改与考核出题。

---

## 一、病害知识

| 条目 | 概要 |
|------|------|
| 苹果炭疽病 | 果实与叶片病斑，褐色下陷、同心轮纹，绯红色黏液；清园+保护剂预防+治疗剂。 |
| 梨黑星病 | 叶、果黑色霉层，叶早落、果凹陷龟裂；清园+氟硅唑/戊唑醇等。 |
| 桃褐腐病 | 果实褐腐、灰褐色霉层；清园+苯醚甲环唑/腐霉利+套袋。 |
| 葡萄霜霉病 | 叶背白色霜状霉、叶面黄褐斑；烯酰吗啉/霜脲·锰锌等。 |
| 苹果褐斑病与叶部病害 | 褐斑、枯斑、早期落叶；代森锰锌、多抗霉素等。 |

**内容结构**：症状识别 → 发生规律（部分）→ 防治要点（清园、药剂、栽培）。

---

## 二、虫害知识

| 条目 | 概要 |
|------|------|
| 蚜虫 | 嫩梢叶背刺吸、卷叶煤烟；黄板+吡虫啉/啶虫脒等。 |
| 红蜘蛛（叶螨） | 叶背吸食、失绿枯焦；捕食螨+阿维菌素/乙唑螨腈/矿物油等轮换。 |
| 食心虫 | 蛀果“豆沙馅”；糖醋液+套袋+氯虫苯甲酰胺等适期用药。 |
| 介壳虫 | 枝干叶片固着吸食、煤烟病；若虫期噻嗪酮/螺虫乙酯等。 |

**内容结构**：为害特点 → 识别要点（部分）→ 防治要点（农业、物理、生物、化学）。

---

## 三、防治方案

| 条目 | 概要 |
|------|------|
| 农业防治 | 清园、修剪、肥水、负载、土壤管理。 |
| 物理防治 | 套袋、黄板、糖醋液、诱虫带、刮树皮。 |
| 生物防治 | 天敌保护与释放（捕食螨、瓢虫、赤眼蜂等）、生物农药。 |
| 化学防治要点 | 对症选药、适期、轮换、安全间隔；常见药剂举例。 |

## 四、通用知识

| 条目 | 概要 |
|------|------|
| 施肥管理 | 秋施基肥（9—10 月）、追肥与叶面肥、水肥结合。 |
| 修剪管理 | 冬剪与夏剪、拉枝开角、两调一控。 |
| 灌溉管理 | 该浇则浇、该控则控，膨大期细水勤灌、封冻水。 |
| 果园管理核心要点 | “当年叶片下年肥”“无光不结果”“叶靠根长、根靠叶养”；保护叶片、合理负载。 |

## 数据与引用说明

- **存放位置**：`lib/data/knowledge_repository.dart`，每条为 `KnowledgeItem`（id、categoryId、title、summary、content）。
- **分类 ID**：`disease` / `pest` / `control` / `general`，与首页四个入口一致。
- **内容来源**：结合常见植保与栽培文献、生产实践整理；部分参考了果树炭疽病、黑星病、蚜虫、红蜘蛛、食心虫、果园施肥与修剪等公开资料，已做精简与统一表述，便于 App 展示与后续扩展。
- **扩展**：新增条目可在 `_buildItems()` 中追加 `KnowledgeItem`；修改某条只需改对应 content/summary/title。

---

## 路由与页面

- 知识库首页 → 点击「病害知识」等 → `/knowledge/category/{disease|pest|control|general}` 列表页 → 点击某条 → `/knowledge/detail?id=xxx` 详情页。
- 列表页：`KnowledgeListScreen`；详情页：`KnowledgeDetailScreen`（按 id 从 `KnowledgeRepository.getById` 取内容并分段显示）。
