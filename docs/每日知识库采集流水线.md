# 每日知识库采集流水线

## 总体顺序（先 GitHub 构建，后 App 消费）

```text
① 构建期（afsa-knowledge 仓库 / GitHub Actions / 本机 cron）
   本地数据集 + 外部数据集网站 + 自爬登记
   → 每日选种（≥10 种病害/虫害，近 2 天降权）
   → 每种种 5–10 张 HQ 图
   → 按标注生成中英文简介
   → push 到 GitHub

② 运行期（手机 App）
   已部署 API 读取该知识库
   → GET /knowledge/feed（首屏 10 条、下拉再 10 条、已读降权）
   → POST /knowledge/reads（阅读记录概率上传 + 个人仓 jsonl）
```

App **不在运行时**爬数据集或搜 GitHub 原始文件；只通过 **知识库 API 阅读流** 做筛选推荐。

---

## 目标

在 **GitHub（afsa-knowledge）** 上每日自动：

1. 从 **本地数据集目录**（`dataset_catalog.json`）+ **外部数据集登记**（Roboflow 等）发现病害/虫害**种类**
2. 每天至少 **10 种**（约 70% 病害 / 30% 虫害），且尽量与 **近 2 天**已采集种类不同（**近期种类降权**）
3. 每种 **5–10 张**高质量图片（短边≥512 + 清晰度评分；优先 `local_image_index.json` 缓存）
4. 数据库图片**无文字说明** → 根据数据集 **标注类别名** + `i18n.py` 词典生成 **中英文**简介（配合 App `locale`）
5. 写入 `knowledge_items.json` / `knowledge_items_en.json` 并 push

若首轮选中的种类图片不足，脚本会**自动回填**其他种类，直到凑满 10 种或候选池耗尽。

---

## 架构

```text
构建期（GitHub Actions 每日 / 或本机 cron）
  dataset_catalog.json  →  种类池（本地 + 外部登记）
  ingest_history.json   →  近2天种类降权
  local_image_index.json + 本地路径  →  5-10 张/种
  ↓
  daily_ingest.py
  ↓
  knowledge_items.json + images/ + knowledge.db
  ↓ git push

运行期（App）
  baseUrl/knowledge/feed  ← 已部署 API（同步 afsa-knowledge main）
  POST /knowledge/reads   ← 阅读记录 + 个人仓 jsonl
```

---

## 种类选择权重

```text
weight(type) =
  0.12  若该种类出现在近 2 天 ingest_history
  0.45  若出现在 3–7 天前
  1.00  更久未出现或未出现
```

每天加权随机抽取 ≥10 种（约 70% 病害 / 30% 虫害，见 `data/ingest_config.json`）。

## 本地 vs GitHub Runner

| 环境 | 能做什么 |
|------|----------|
| **本机**（有 `disease_recognition/database`） | 完整流程：选种 + 取图 + 双语正文 + push |
| **GitHub `ubuntu-latest`** | 用仓内 `dataset_catalog.json` 选种；**无本地路径则无法取新图**（会 skip） |
| **自建 Runner**（推荐） | 设置仓库 Variable `AFSA_REGISTRY_PATH`，与本地相同 |

本机手动跑：

```bash
cd /home/yuhanlin/APP/konwledgeset
export AFSA_REGISTRY_PATH=/home/yuhanlin/APP/AFSA/data/disease_classification/manifest/registry.json
python3 scripts/sync_dataset_catalog.py
python3 scripts/daily_ingest.py
git push origin main
```

## 外部数据集（Roboflow 等）

- 登记：`scripts/crawl_roboflow_catalog.py --add entry.json`（写入 `dataset_catalog.json`，**不与本地重复**）
- 日志：`data/external_crawl_log.jsonl`
- 搜索种子：`data/ingest_search_seeds.json`（可扩展 manual_candidates）

爬取到新集后，需将样本同步到可访问路径（或下载到 `data/external_downloads/`），再纳入 catalog。

## 知识条目字段

| 字段 | 说明 |
|------|------|
| `image_url` | 封面图 |
| `image_gallery` | 5–10 张 `/knowledge/images/...` |
| `image_source` | `dataset_id`, `label_slug`, 溯源 |
| `title` / `content` | 中/英分文件存储 |

简介由标注 slug + `i18n.py` 作物/病虫害词典生成；后续可接植保资料检索增强 `content_sources`。

## App 端（不变）

```http
GET  /knowledge/feed?limit=10&user_id={github_login}&locale=zh
POST /knowledge/reads
```

App **不**在运行时爬数据集；只消费 **已 push 的知识库 + API 阅读流**。
