# 知识库说明与后台接口规范

本文档面向**服务端实现**：说明知识库能力、**搜索方式**、**简洁传输约定**（有限流量、最大信息），以及后台**最简单存储与检索**要求。

---

## 一、知识库与搜索说明

### 1.1 功能

- **知识库**：App 内以**卡片流**形式展示「病害 / 虫害 / 防治 / 通用」知识；支持按分类 Tab、分页加载。
- **搜索**：仅限后台知识库内的**搜索引擎**，支持：
  - **关键词**：匹配标题、摘要（后台用 LIKE 或等价方式即可）。
  - **标签筛选**：水果种类、病害种类、防治方法类别（与筛选选项的 id 一致）。
- **详情**：用户点击某张卡片时，再按 `id` 拉取该条**完整正文**，列表接口不返回正文以省流量。

### 1.2 传输原则：有限流量、最大信息

- **列表/搜索**：只返回**紧凑条目**（id、分类、标题、摘要、标签），**不返回 content**；分页（page + limit）控制单次条数。
- **详情**：仅当用户打开某条时请求一次，返回**含 content** 的完整对象。
- 可选：列表项支持**短键**（见下）进一步减小 JSON 体积。

---

## 二、搜索方式（后台如何实现）

- **入口**：与列表共用同一接口 `GET /knowledge/items`，通过查询参数区分「按分类浏览」与「搜索」。
- **参数**：
  - `keyword`：关键词，后台对**标题、摘要**做模糊匹配（如 SQL `LIKE '%keyword%'` 或简单包含判断）。
  - `category_id`：分类过滤（disease / pest / control / general；或 all 表示不按分类）。
  - `fruit_type`、`disease_type`、`control_type`：标签精确匹配（与 `/knowledge/filters` 返回的 id 一致）。
  - `page`、`limit`：分页，默认 `limit=20`。
- **逻辑**：  
  `WHERE (keyword 为空 OR title LIKE %keyword% OR summary LIKE %keyword%)  
   AND (category_id 为空/all 或 category_id = ?)  
   AND (fruit_type 为空或 fruit_type = ?)  
   AND (disease_type 为空或 disease_type = ?)  
   AND (control_type 为空或 control_type = ?)  
   ORDER BY id 或更新时间  
   LIMIT limit OFFSET (page-1)*limit`  
  无需全文检索引擎，**简单 LIKE + 条件即可**。

---

## 三、后台存储与检索（最简单方式）

- **存储**：单表即可。例如：
  - `id`（主键）, `category_id`, `title`, `summary`, `content`
  - `fruit_type`, `disease_type`, `control_type`（可选，用于筛选）
  - 若有更多标签，可再加列或存 JSON。
- **检索**：
  - 列表/搜索：按上面「搜索方式」用 **LIKE + 等值条件 + LIMIT/OFFSET** 即可。
  - 详情：按 `id` 查单条，返回含 `content`。
- **数据量**：支持**大量**知识条目的分页与搜索，不要求一次性加载全部。

---

## 四、接口方法一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/knowledge/filters` | 筛选选项（水果/病害/防治类别），用于搜索页标签 |
| GET | `/knowledge/items` | 列表 + **搜索**（分页、紧凑格式、不含 content） |
| GET | `/knowledge/items/:id` | 单条详情（**含 content**） |

---

## 五、接口详细约定

### 5.1 筛选选项 `GET /knowledge/filters`

- **请求**：无参数。
- **响应**：JSON 对象，字段名可用驼峰或下划线。

```json
{
  "fruitTypes": [{"id": "apple", "name": "苹果"}, {"id": "pear", "name": "梨"}],
  "diseaseTypes": [{"id": "anthracnose", "name": "炭疽病"}],
  "controlTypes": [{"id": "agricultural", "name": "农业防治"}]
}
```

- 未实现或 404 时，App 用内置选项。

---

### 5.2 列表与搜索 `GET /knowledge/items`

- **请求**：仅查询参数，全部可选。

| 参数 | 说明 |
|------|------|
| category_id | 分类：disease / pest / control / general；不传或 all 表示全部 |
| fruit_type | 水果种类 id |
| disease_type | 病害种类 id |
| control_type | 防治方法类别 id |
| keyword | 关键词，匹配标题、摘要 |
| page | 页码，从 1 开始 |
| limit | 每页条数，建议默认 20 |

- **响应（紧凑，不含 content）**：二选一。
  - **方式 A（推荐）**：对象 `{ "items": [ {...}, ... ], "has_more": true/false }`  
    - `items`：本条目的知识列表，**每条不要带 content**。  
    - `has_more`：是否还有下一页。
  - **方式 B**：直接返回数组 `[ {...}, ... ]`，App 根据 `length >= limit` 判断 has_more。

- **单条结构（列表项）**：支持全键或短键，任选一种即可。

**全键（可读性好）**：

```json
{
  "id": "disease_apple_anthracnose",
  "category_id": "disease",
  "title": "苹果炭疽病",
  "summary": "果实与叶片常见病害…",
  "fruit_types": ["苹果"],
  "disease_type": "anthracnose",
  "control_type": "chemical"
}
```

**短键（省流量）**：`c`=category_id, `t`=title, `s`=summary, `ft`=fruit_type, `dt`=disease_type, `ct`=control_type

```json
{
  "id": "disease_apple_anthracnose",
  "c": "disease",
  "t": "苹果炭疽病",
  "s": "果实与叶片常见病害…",
  "ft": "apple",
  "dt": "anthracnose",
  "ct": "chemical"
}
```

- **注意**：列表/搜索响应里**不要包含 content**，以控制流量；正文仅在详情接口返回。

---

### 5.3 详情 `GET /knowledge/items/:id`

- **请求**：路径参数 `id`。
- **响应**：单条完整对象，**必须包含 content**；其余字段同列表项（可用全键或短键）。

```json
{
  "id": "disease_apple_anthracnose",
  "category_id": "disease",
  "title": "苹果炭疽病",
  "summary": "果实与叶片常见病害…",
  "content": "【症状识别】\n• 果实：初期为淡褐色小圆斑…",
  "fruit_types": ["苹果"],
  "disease_type": "anthracnose",
  "control_type": "chemical"
}
```

## 六、App 端行为小结

| 场景 | 请求 | 说明 |
|------|------|------|
| 知识库首页（按 Tab） | GET /knowledge/items?category_id=xxx&page=1&limit=20 | 紧凑列表，卡片流展示 |
| 加载更多 | GET /knowledge/items?category_id=xxx&page=2&limit=20 | 追加卡片 |
| 搜索 | GET /knowledge/items?keyword=xx&fruit_type=xx&…&page=1&limit=20 | 同上，带关键词与标签 |
| 搜索加载更多 | page 递增 | 同上 |
| 点击某张卡片 | GET /knowledge/items/:id | 仅此时拉取 content，展示详情 |
| 搜索页筛选选项 | GET /knowledge/filters | 标签选项 |

---

## 七、总结

- **搜索方式**：与列表共用 `GET /knowledge/items`，通过 `keyword` + `fruit_type` / `disease_type` / `control_type` 实现；后台用**简单 LIKE + 条件 + 分页**即可，无需全文引擎。
- **有限流量、最大信息**：列表/搜索只返回紧凑条目（无 content），分页；详情按需按 id 拉取 content。
- **后台**：**最简单存储**（单表 + 必要字段）、**最简单检索**（LIKE + 等值 + LIMIT/OFFSET），支持大量知识条目。
- **前端**：知识库以**卡片形式**展示，分页加载；点击卡片再请求详情，保证传输简洁、信息集中。
